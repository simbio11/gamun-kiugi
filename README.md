# 가문 키우기

도트 그래픽 가문 육성 시뮬레이션. 모바일 웹(PWA).

**다섯 살부터 → 학창 시절 → 수능·입시 → 진로 → 결혼 → 자녀·손주 → 유언과 승계**, 무한 반복.

- **다섯 살부터 시작**: 부모님 직업·재산·형제자매는 무작위(운명). 그 전까지의 능력치도 운
- **학창 시절**: 해마다 학원·과외·인강·동아리·놀기·연애·알바 중 고르면 성적과 사교육비가 쌓인다
- **수능과 입시**: 백분위·등급 → 성적에 맞춰 추천되는 대학·학과(상향·소신·적정·안정, 경쟁률) → 원서 3장 → 합격 발표 → 등록 or 재수·삼수…
- **전공이 진로를 연다**: 의대→의사, 한의대→한의사, 교대→초등 임용, 사범대→중등 임용, 로스쿨→변호사시험→판사·검사, 경영→공채·CPA·로스쿨 …
- **직업 119종** (14개 분야). 공무원·임용·CPA·변호사시험 등은 붙을 때까지 매년 응시(독학/인강/학원/고시원), 포기 가능. 창작 직업은 대부분 안 뜬다
- **인생사**: 병역(판정 등급·육군/해병/공군/카투사/장교/사회복무/기피), 암(병기·치료 선택·5년 생존율), 교통사고, 우울증, 부부 금슬→위기→이혼·재혼, 외도, 난임→시험관·입양, 쌍둥이, 전세사기·보이스피싱, 명예퇴직→인생 2막, 길거리 캐스팅, 올림피아드, 올림픽, 노벨상, 상장, 장관 청문회, 대통령 선거 …
- **성격** 17종 (성실·게으름·낙천·예민·바람기·일편단심·강골·병약…), 부모에게서 일부 유전
- **소개팅 → 프러포즈**. 나이가 들수록 빈도·후보·성공률이 떨어지고, 번듯한 직장이 없으면 불리
- **부모님 유산**: 형제와 법대로 / 어머니께 / 기여분 주장 / 더 챙기기 / 양보 → 형제 반응
- **유언장**: 쓰면 뜻대로 되지만 수명이 줄고, 안 쓰면 오래 살지만 떠난 뒤 급매·다툼
- **승계**: 가주가 떠나면 자손 중 누구로 이어갈지 고른다. 직접 이끄는 건 내 자손뿐 (형제의 자손은 방계)
- 개인/가문 재산 장부, 부동산·상가 건물·주식·코인·예술품(위작), 상속세·증여세(10년 합산·세대생략 할증), 세무사
- **업적 72개** + 세대마다 **세대 미션 3개** + **직업 도감**
- 얼굴은 유전자로 절차 생성되는 16×16 도트 초상화. 부모를 닮되 형제끼리도 제각각
- 확률은 통계를 참고 (초혼 연령 남 33.9·여 31.6세, 기대수명 남 80.8·여 86.6세, 암 평생 발병 남 44.6%·여 38.2%, 현역 판정 86%, 다태아 5.5% 등)

기획서: [docs/GDD.md](docs/GDD.md)

## 실행

```bash
npm install
npm run dev      # 휴대폰에서 같은 와이파이로 접속 가능 (--host)
npm test         # 시뮬레이션 테스트 (200년 자동 플레이 포함)
npm run build    # dist/ → 정적 호스팅
```

## 구조

```
src/core/     시뮬레이션 (UI 없음, 시드 기반 RNG로 재현 가능)
  sim.ts        새 게임, 한 해 진행, 이벤트 처리, 플레이어 행동
  jobs.ts       직업 119종, 시험, 준비 방식
  school.ts     학년 생활, 수능, 대학·학과, 입시
  life.ts       인생사 (병역·질병·결혼생활·난임·사기·영광…)
  family.ts     부모님 유산, 유언장, 후계자 선택
  missions.ts   세대 미션
  events.ts     이벤트와 선택지 (나이 마일스톤, 진로, 시험, 소개팅, 랜덤)
  registry.ts   이벤트 모음
  people.ts     인물, 유전, 관계
  growth.ts     능력치 성장, 노화, 사망 확률
  economy.ts    직업별 수입, 지출, 자산 시장, 파산
  achievements.ts 업적
  estate.ts     상속 정산, 승계, 증여
  tax.ts        상속세, 증여세
  data.ts       재능, 직업, 시험, 세율, 자산, 이름 등의 데이터
src/render/   도트 초상화 생성
src/ui/       화면
```
