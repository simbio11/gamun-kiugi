# 가문 키우기

도트 그래픽 가문 육성 시뮬레이션. 모바일 웹(PWA).

**다섯 살부터 → 학창 시절 → 수능·입시 → 진로 → 결혼 → 자녀·손주 → 유언과 승계**, 무한 반복.

- **다섯 살부터 시작**: 부모님 직업·재산·형제자매는 무작위(운명). 그 전까지의 능력치도 운
- **학창 시절**: 해마다 학원·과외·인강·동아리·놀기·연애·알바 중 고르면 성적과 사교육비가 쌓인다
- **수능과 입시**: 백분위·등급 → 성적에 맞춰 추천되는 대학·학과(상향·소신·적정·안정, 경쟁률) → 원서 3장 → 합격 발표 → 등록 or 재수·삼수…
- **전공이 진로를 연다**: 의대→의사, 한의대→한의사, 교대→초등 임용, 사범대→중등 임용, 로스쿨→변호사시험→판사·검사, 경영→공채·CPA·로스쿨 …
- **직업 128종** (14개 분야). 공무원·임용·CPA·변호사시험 등은 붙을 때까지 매년 응시(독학/인강/학원/고시원), 포기 가능. 창작 직업은 대부분 안 뜬다
- **히든 직업 43종**: 평범한 길 위의 사건·숨은 길(단서→세 단계)·슈퍼 히든(3단계 연작 9종) 위에 **히든의 히든 9종** — ① 죽음의 문턱 (뱀파이어·사이보그: 2040년 이후 재산 50억이면 죽음의 순간 35% 확률로 뇌 이식 수술) ② 3단계 연작 (아홉 꼬리 신부·계약서의 여주인·시간 정지의 여제·색욕의 성녀) ③ 단일 대형 이벤트 (향의 연금술사·독의 소믈리에) ④ 배우자 (글리치 메이드: 40세까지 장가 못 든 남성 가주가 41세에 20% 확률로 안드로이드 신부를 얻는다)
- **인생사**: 병역(판정 등급·육군/해병/공군/카투사/장교/사회복무/기피), 암(병기·치료 선택·5년 생존율), 교통사고, 우울증, 부부 금슬→위기→이혼·재혼, 외도, 난임→시험관·입양, 쌍둥이, 전세사기·보이스피싱, 명예퇴직→인생 2막, 길거리 캐스팅, 올림피아드, 올림픽, 노벨상, 상장, 장관 청문회, 대통령 선거 …
- **행동 탭 (주도적 행동)**: 해마다 행동력 3으로 턴을 넘기기 전에 직접 한다. 가족 여행·배우자와 데이트·자녀/손주와 깊은 대화(마음속 흔적 힌트)·부모님 찾아뵙기·손주 돌보기·혼사 추진(중매)·결혼 재촉·진로 다시 고민하기·이직·자격증·운동·종합검진·특강·적성검사·조기유학·부동산 임장·아트페어·봉사·인맥 관리·장학금·정치 활동. 가주가 어릴 땐 공부 계획·친구·운동·예체능·부모님 돕기·용돈 모으기. 자산 탭에서 적립식 자동 증여
- **떡밥 (보이지 않는 흔적)**: 사소한 선택도 따뜻함·상처·공부 습관·운동·예술·선행·정직·요령·한탕·건강 무시·인맥·절약·과소비·연애 상처·가족 시간·효심 같은 흔적을 남긴다. 흔적은 능력·확률에 조용히 스며들고(공부 효율, 수명, 연애, 승진, 금슬), 관련 사건을 더 자주 부르며, 쌓이면 몇 년~수십 년 뒤 회수된다 (어릴 적 상처 → 커서 원망·절연 / 따뜻함 → 효도 용돈 / 선행 → 은인의 보답 / 요령 → 들통 / 건강 무시 → 쓰러짐 / 운동 경험 → 스카우트 …)
- **후폭풍**: 지금의 선택이 몇 년 뒤 돌아온다. 친구 보증 → 부도·구상권 소송 or 친구의 보답, 돈 빌려주기(차용증) → 상환·잠수·대박, 엔젤 투자 → 폐업·엑싯·유니콘, 폰지(배당 몇 번 뒤 붕괴), 청약통장 → 당첨, 재개발 → 입주·표류, 보험 → 진단비·사망보험금, 건강검진 → 암 조기 발견, 음주운전 습관, 층간소음 전쟁, 학창 시절 첫사랑 재회, 학폭 폭로·늦은 사과, 기부 → 장학생의 보답, 반려견과의 이별, 조기유학 → 해외 정착, 다단계 …
- **일상 이야기 90여 개**: 첫 심부름·반장 선거·게임 중독·덕질·수학여행·MT·워홀·첫 월급·야근·상사 갑질·사내 연애·육아휴직·고부 갈등·제사·김장·환갑·황혼 육아·탈모·갱년기·동창회·트로트 오디션·경로당·월드컵·태풍·의인 …
- 자손 없이 떠나면 조카를 **양자로 입적**해 대를 잇는다
- **성격** 17종 (성실·게으름·낙천·예민·바람기·일편단심·강골·병약…), 부모에게서 일부 유전
- **연애**: 소개팅·결혼정보회사·자연스러운 만남(동아리·직장·여행·앱…) → 사귀는 동안 해마다 일이 생긴다 (달달·다툼·권태기·장거리·결혼 재촉·바람·혼전임신·동거·상대의 프러포즈·이별 통보) → 프러포즈 → 상견례(부모 반대·파혼)·결혼식 규모·신혼집 → 결혼. 연애가 곧 결혼은 아니다. 자녀의 연애는 알아서 흘러가고 결혼 허락만 구하러 온다
- 나이가 들수록 만남·성공률이 떨어지고, 번듯한 직장이 없으면 불리
- **부모님 유산**: 형제와 법대로 / 어머니께 / 기여분 주장 / 더 챙기기 / 양보 → 형제 반응
- **유언장**: 쓰면 뜻대로 되지만 수명이 줄고, 안 쓰면 오래 살지만 떠난 뒤 급매·다툼
- **승계**: 가주가 떠나면 자손 중 누구로 이어갈지 고른다. 직접 이끄는 건 내 자손뿐 (형제의 자손은 방계)
- 개인/가문 재산 장부, 부동산·상가 건물·주식·코인·예술품(위작), 상속세·증여세(10년 합산·세대생략 할증), 세무사
- **업적 79개** + 세대마다 **세대 미션 3개** + **직업 도감**
- 얼굴은 유전자로 절차 생성되는 16×16 도트 초상화. 부모를 닮되 형제끼리도 제각각
- 확률은 통계를 참고 (초혼 연령 남 33.9·여 31.6세, 기대수명 남 80.8·여 86.6세, 암 평생 발병 남 44.6%·여 38.2%, 현역 판정 86%, 다태아 5.5% 등)

## 실행

```bash
npm install
npm run dev      # 휴대폰에서 같은 와이파이로 접속 가능 (--host)
npm test         # 시뮬레이션 테스트 (200년 자동 플레이 포함)
npm run build    # dist/ → 정적 호스팅
```

## 구조

```
src/core/     시뮬레이션 (UI 없음, 시드 기반 RNG로 재현 가능)
  sim.ts        새 게임, 한 해 진행, 이벤트 처리, 플레이어 행동
  jobs.ts       직업 128종, 시험, 준비 방식
  school.ts     학년 생활, 수능, 대학·학과, 입시
  life.ts       인생사 (병역·질병·결혼생활·난임·사기·영광…)
  family.ts     부모님 유산, 유언장, 후계자 선택
  actions.ts    행동 탭 (주도적 행동, 적립식 증여)
  seeds.ts      떡밥 회수 이벤트
  marks.ts      흔적의 보이지 않는 효과
  romance.ts    연애 (만남·사귐·이별·상견례·결혼)
  stories.ts    일상 이야기 (데이터 형식으로 쓰는 작은 이벤트)
  fate.ts       후폭풍 (예약된 사건: 보증·대여·투자·청약·보험·첫사랑…)
  missions.ts   세대 미션
  events.ts     이벤트와 선택지 (나이 마일스톤, 진로, 시험, 소개팅, 랜덤)
  registry.ts   이벤트 모음
  people.ts     인물, 유전, 관계
  growth.ts     능력치 성장, 노화, 사망 확률
  economy.ts    직업별 수입, 지출, 자산 시장, 파산
  achievements.ts 업적
  estate.ts     상속 정산, 승계, 증여
  tax.ts        상속세, 증여세
  data.ts       재능, 직업, 시험, 세율, 자산, 이름 등의 데이터
src/render/   도트 초상화 생성
src/ui/       화면
```
