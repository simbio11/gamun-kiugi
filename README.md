# 가문 키우기

도트 그래픽 가문 육성 시뮬레이션. 모바일 웹(PWA).

**육성 → 혼인 → 출산 → 승계 → 다음 세대**, 무한 반복.

- 1턴 = 1년. 연간 방침(생활 방식·자녀 교육비·집중 분야)을 정해두고, 해마다 나오는 이벤트에서 선택
- 능력치 5개(근력·지능·매력·성품·건강)는 **잠재력(유전) + 실제치(육성)**. 재산은 보유 자산의 합계
- 재능은 숨겨져 있다가 이벤트·적성검사·투자로 발견됨. 재능에 맞는 길을 고르면 잘 풀림
- 개인 재산 / 가문 재산 장부, 부동산 시장, 상속세·증여세(10년 합산), 유언장, 후계자 지명, 형제 불만
- 얼굴은 유전자로 절차 생성되는 16×16 도트 초상화. 부모와 닮은 아이가 태어남

기획서: [docs/GDD.md](docs/GDD.md)

## 실행

```bash
npm install
npm run dev      # 휴대폰에서 같은 와이파이로 접속 가능 (--host)
npm test         # 시뮬레이션 테스트 (200년 자동 플레이 포함)
npm run build    # dist/ → 정적 호스팅
```

## 구조

```
src/core/     시뮬레이션 (UI 없음, 시드 기반 RNG로 재현 가능)
  sim.ts        새 게임, 한 해 진행, 이벤트 처리, 플레이어 행동
  events.ts     이벤트와 선택지 (나이 마일스톤, 혼인, 진로, 랜덤)
  people.ts     인물, 유전, 관계
  growth.ts     능력치 성장, 노화, 사망 확률
  economy.ts    수입, 지출, 부동산 시장
  estate.ts     상속 정산, 승계, 증여
  tax.ts        상속세, 증여세
  data.ts       재능, 직업, 세율, 이름 등의 데이터
src/render/   도트 초상화 생성
src/ui/       화면
```
