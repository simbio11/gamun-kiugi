## 1. 가훈 + 가문 특성 트리 (Legacy Tree) 🆕

**재구성:** 유산 상점(소모형)과 별개로, 계정에 **영구 특성**을 찍는다. 화폐는 같은 🏺 유산이고, 가문이 끝날 때 쌓인다.

- **가문 레벨** = 지금까지 끝낸 가문들의 누적 유산 (예: 100마다 1레벨) → 레벨마다 특성 포인트 1
- **세 갈래 + 가훈**: 새 가문을 세울 때 가훈 하나를 고르면 그 갈래 특성만 켜진다 (빌드 목표가 생긴다)

| 갈래 (가훈 예) | 1단계 | 2단계 | 3단계 (궁극) |
|---|---|---|---|
| 📚 학자 명문가 「배움에는 끝이 없다」 | 사교육 효율 +15% | 수능 찍기 보정 (+3점) · 장학금 확률↑ | 교수 임용·논문 +25%, 대학원 학비 −50% |
| 🏢 부동산·자산가 「땅은 배신하지 않는다」 | 대출 한도 +10% (LTV) | 전세사기·부업 사기 간파 +30% | 증여세 10% 감면 · 경매 낙찰 보정 |
| 🎨 돌연변이·예술가 「남과 다르게」 | 히든 직업 제안 ×1.3 | 괴짜 성격(rebel·dreamer) 발현↑ | 슈퍼 히든 ×1.5, 창작 직업 대박 확률↑ |
| (추가 후보) ⚖ 법조 · 🩺 의료 · 🗳 정치 | 그 직업 시험 +5 | 진입 직후 직급 +1 | 정점 이벤트 확률↑ |

- **연결:** 이미 있는 `hiddenMastery`·`examScore`·`giftTax`·`buyPower` 계산에 배율 하나씩만 더하면 된다 (코드 영향 작음).
- **목표 의식:** 가문 시작 화면에 "이번 가훈: 의사 집안 5대" 같은 **세대 목표**(기존 세대 미션 확장)를 띄운다.

## 2. 세대를 관통하는 숙적 가문 🟡 → 보강

**지금:** 라이벌 가문은 재산·명성이 해마다 움직이고, 가끔 부딪치고, 사돈이 될 수 있다. 대표 인물은 바뀌지만 **"그 사람의 자식"이라는 연결은 없다.**

**보강안:**
1. 라이벌 가문에도 **가상의 족보 3대**(이름·나이·직업만)를 둔다 → 1대 가주의 전교 1등 경쟁자 → 그 자식이 2대 가주 자식의 **면접관·직장 상사·소개팅 상대**로 등장.
2. **로미오와 줄리엣:** 양가 자녀가 사귀면 "두 집안의 반대" 미니 체인 → 결혼하면 `allied`(동맹), 깨지면 앙심 +20.
3. **가문 랭킹 보드** (계정 화면): 우리 가문 vs 라이벌의 재산·명성 그래프를 세대별로.
4. 앙숙이 깊어지면(feud 70+): 적대적 인수합병(가업 지분 공격), 선거 때 스캔들 폭로, 가업 하청 끊기.

## 3. 상속 분쟁 미니 드라마 🟡 → 보강

**지금:** 유언장을 쓰면 수명이 줄고, 안 쓰면 법정상속. 불만이 있으면 `grievance` 이벤트.
**이번에 들어감 ✅:** 생전 승계 때 형제의 불만 → "유류분 청구하겠다" 이벤트, 효도 계약 위반 증여 취소 소송.

**보강안 (가주 사망 직후 3막 컷씬):**
| 막 | 조건 | 내용 |
|---|---|---|
| 1막 빈소 | 유언장 없음 + 자녀 2명 이상 | 조문객 앞에서 "아버지가 나한테 집 준다고 했어" 말다툼 |
| 2막 협의 | 자녀 성향(탐욕·효심·야망) | 상속재산 분할 협의: 나눠 주기 / 장자 우선 / 가업은 한 명 |
| 3막 법정 | 협의 실패 | 장남 vs 차남 상속 소송 · 유류분 반환 청구 (법정상속분의 1/2) · 가문 쪼개기(방계 독립: 일부 자산과 함께 가계도에서 분가) |

- 연출: 기존 신문(호외) 틀을 써서 "○○가 형제 상속 소송" 기사 컷.
- 유언장 딜레마 강조: 유언장 작성 화면에 "안 쓰면 분쟁 확률 N%" 미리 보기.

## 4. 인생 신문 1면 / 영수증 카드 ✅ (1차)

**이번에 들어감:** 가계도에서 돌아가신 분을 누르면 **🗞 인생 신문 한 줄**이 나오고, **이미지로 저장·공유**(모바일은 공유 시트, PC는 PNG 저장)할 수 있다. 연대기에서 그 사람의 굵직한 순간(합격·개원·당선·부도·옥살이·전세사기·암…)을 골라 "고생 → 성취 → 영면"으로 엮는다.

**실제 자동 플레이에서 나온 헤드라인 예시:**
- [경제면] 향년 75세로 별세한 2대 가주 박온새… 시험에 붙었고 창업가 대기업 총수로 은퇴해 영면 — "하루도 허투루 살지 않았다"
- [사회면] 향년 85세로 별세한 1대 가주 김주원… 옥살이·전세사기 딛고 영면 — "넘어진 만큼 일어났다"
- [경제면] 향년 92세로 별세한 이씨 가문 이영수… 부도 딛고 건물주로 은퇴해 영면
- [사회면] 향년 87세로 별세한 2대 가주 이순자… 시험에 붙었고 공무원 3급 부이사관으로 은퇴해 영면

**목표 예시 (다음 단계):** `[사회면] 향년 74세로 별세한 3대 가주 김철수… 의대 4수 끝에 개원했으나 코인 폭락과 전세사기 딛고 건물주로 영면`
- 필요한 것: "n수"를 시험 이름과 묶기(지금은 "다섯 수 넘게"만), 직업 이력 2~3개 기록, 시대 사건(IMF·광주) 연결.
- **영수증 카드** 형식 (같은 데이터, 다른 틀):
  ```
  ┌────────── 김철수 인생 영수증 ──────────┐
  │ 1952 출생 ··························· 1 │
  │ 의대 입시 (4수) ················ -4년 │
  │ 개원 ························· +3.2억/년 │
  │ 코인 폭락 ························ -8억 │
  │ 전세사기 ························· -3억 │
  │ 건물주 ··························· +40억 │
  │ 자녀 3 · 손주 7 ··················· ♥♥♥ │
  │ 합계: 인생 점수 214 (SS) · 향년 74   │
  └────── 감사합니다. 또 오세요 ───────┘
  ```
- 가주가 세상을 떠날 때 승계 알림 창에 **자동으로 1면을 띄우고** "공유" 버튼을 바로 보여 준다.

## 5. 도트 가계도 박물관 🟡 → 보강

**지금:** 가계도(트리/목록, 크게·보통·작게), 사람을 누르면 생애 요약·재산·직업·인생 성적·(이번에) 인생 신문.
**보강안:** 핀치 줌·드래그 이동(수백 명 규모), 세대별 띠 색, 돌아가신 분은 액자 테두리, "이 사람이 남긴 유산·카드·가보" 탭, 가문 대표 10인 "명예의 벽".

## 6. 고속 진행 · 오토 런 🆕

| 기능 | 해금 | 동작 |
|---|---|---|
| 📚 학창 플랜 자동 반복 | 1대 완료 | 매 학년 "어떻게 보낼까"를 지난번 선택으로 자동 처리 (형편이 바뀌면 멈춤) |
| ⏩ 오토 런 | 1대 완료 | 해마다 자동 진행, **중대 사건**(수능·진로·병·연애·결혼·사고·떡밥 회수·대형 이벤트·역사 사건·승계)에서만 멈춤. 나머지 일상 이야기는 "무난한 선택"(위험·비용 없는 선택지)으로 처리 |
| ⏭ N년 건너뛰기 | 2대 완료 | 가주가 아이일 때 5년씩 |

- 멈춤 기준은 이벤트 id 목록으로 관리 (`CORE_IDS` 와 비슷하게 `STOP_IDS`).
