# 가문 키우기 — 게임 기획서 (GDD v0.1)

> 도트 그래픽 모바일 시뮬레이션 육성 게임.
> 육성 → 혼인 → 출산 → 승계 → 다음 세대, 무한 반복.
> 이 문서는 그릴미 세션(2026-09-29)에서 확정한 결정들을 정리한 것. 게임 코드는 별도 레포로 분리 예정.

## 0. 확정 결정 요약

| 항목 | 결정 |
|---|---|
| 플레이 시점 | **현 가주 = 본인.** 본인 인생 + 미성년 자녀 진로 결정. 성인 자녀는 의지(관계도·행복도)가 개입 |
| 시대 | 시작 시 선택: **근현대사 모드**(1950년대~, 시대가 흐름) / **현대 한국 모드**(고정) |
| 목표 | 가문 명성 점수 + 자산 축적 + 미니 미션(업적). 후계자 없이 사망 시 가문 단절 = 게임오버 |
| 능력치 | 근력·지능·매력·성품·건강 = **잠재력(유전) + 실제치(육성)**. 재산 = 보유 자산 합산값(유전 X) |
| 재능 | **숨겨짐**, 이벤트·검사·대회로 발견 |
| 재산 | 은행앱처럼 **개인 재산 / 가문 재산** 분리 표시. 부동산·금융·예술품·가업 |
| 세금 | 상속세·증여세. 절세(합법) + 탈세(세무 주목도 누적 → 세무조사) |
| 승계 | 가주가 **지명** + 형제 불만(유류분·분가·악연). 유언 없으면 법정상속 |
| 관리 범위 | **직계 상세 + 방계 요약** |
| 혼인 | 후보 풀 중 선택 (능력치 일부만 공개), 조건 있음 |
| 턴 | 1턴 = 1년. **연간 방침 + 이벤트 1~3개** |
| 선택지 정보 | **요구 조건만 표시**, 성공확률·장기 결과는 숨김 |
| 사망 | 건강·나이 기반 확률 사망 + 사고/질병. **생전 은퇴(승계) 가능** |
| 기술 | 웹 **TypeScript + Canvas, PWA** |
| 도트 | **절차 생성 초상화**, 외모도 유전 |
| v0.1 | **수직 슬라이스**: 모든 핵심 시스템의 뼈대를 얇게 |

## 1. 코어 루프

```
[연간 방침 설정] → [턴 넘기기(+1년)] → [자동 정산: 성장·수입·지출·시장변동]
      ↑                                        ↓
      └──── [결과 반영] ← [이벤트 1~3개 선택] ←─┘

세대 루프: 육성 → 혼인 → 출산 → 자녀 육성 → (은퇴 or 사망) → 상속·세금 → 승계 → 새 본인
```

### 한 턴(1년)의 순서
1. **연초**: 플레이어가 연간 방침을 확인/수정 (바꾸지 않으면 작년 그대로)
2. **정산**: 나이 +1 → 능력치 성장/노화 → 급여·임대수익·지출 → 자산 가격 변동
3. **이벤트**: 마일스톤(나이 도달) 우선, 남는 슬롯에 랜덤 이벤트. 최대 3개
4. **판정**: 사망/질병 체크, 업적 체크, 방계 요약 로그 생성
5. **연말 리포트**: "1987년 — 장남 입학, 강남 아파트 +18%, 재산 12.4억"

## 2. 인물 모델

```ts
Person {
  id, name, sex, birthYear, deathYear?
  parents: [id, id], spouse?, children: []
  potential: { str, int, cha, mor, hp }   // 1~100, 유전, 불변
  actual:    { str, int, cha, mor, hp }   // 육성으로 채움, potential이 상한
  talents: Talent[]                       // discovered 플래그 포함
  appearance: Genes                       // 머리형/머리색/피부/눈/체형
  job?, jobLevel, education[]             // 경력·학력
  flags: Set<string>                      // "사립초", "재수", "검정고시", "전과" …
  affinity: number                        // 가주와의 관계도 -100~100
  happiness: number                       // 숨은 값 0~100
  desire?: CareerTag                      // 본인이 원하는 진로 (성장하며 드러남)
  wallet: AssetId[]                       // 개인 재산
}
```

### 능력치 5개 + 재산
| 능력치 | 쓰임 | 나이 곡선 |
|---|---|---|
| 근력 | 운동선수·군인·육체노동, 사고 생존 | 10~25세 성장 최적, 40+ 감소 |
| 지능 | 학업·시험·전문직·투자 판단 | 5~20세 최적, 이후 느림 |
| 매력 | 혼인 후보 질, 연예·영업·정치, 인플루언서 | 청소년기 최적, 50+ 감소 |
| 성품 | 관계도 변화폭, 스캔들 저항, 승계 분쟁 완화, 공직 | 전 연령 완만 |
| 건강 | 수명, 질병 확률, 출산 확률 | 노화로 매년 감소, 운동·의료비로 완화 |
| **재산** | **보유 자산 평가액 합계** (계산값, 유전 안 됨) | 시장·수입·상속 |

### 성장 공식 (초안)
```
연간 성장 = 투자량(방침) × 나이효율(능력치별 곡선) × 재능배수 × (1 - actual/potential)
```
- 잠재력 근처일수록 성장이 둔해짐 → 잠재력 낮은 능력치에 올인하면 비용 대비 효율 나쁨
- 재능이 맞으면 배수 ×1.5~2 → "숨은 재능을 찾아서 거기에 투자"가 핵심 전략

### 재능 (숨김, 발견형)
v0.1 4종 → 이후 확장

| 재능 | 효과 | 발견 계기 |
|---|---|---|
| 수재 | 지능 성장 ×1.8, 시험 보정 | 학력평가, 영재원 시험 |
| 운동신경 | 근력 성장 ×1.8, 운동선수 경로 해금 | 체육대회, 스카우트 |
| 스타성 | 매력 성장 ×1.5, 연예·인플루언서 대박 확률 | 오디션, SNS 바이럴 |
| 장사꾼 | 창업·투자 수익 보정 | 용돈 벌이 이벤트, 알바 |
| (이후) 예술혼, 강골(건강), 인덕(성품), 승부사, 병약(부정), 낭비벽(부정) … | | |

- **발견 방법**: ① 나이 이벤트에서 우연히 ② 돈을 써서 적성검사·영재원·학원 체험 ③ 해당 분야에 투자하다 성장률이 이상하게 높음(눈치 싸움)
- 발견 전 UI: `재능: ??? ???`

## 3. 유전

```
자녀 잠재력[s] = (부 잠재력[s] + 모 잠재력[s]) / 2 + N(0, 8), 1~100으로 제한
```
- **재능 유전**: 부모가 가진 재능 각각 30% 확률로 물려받음
- **돌연변이**: 3% 확률로 새 재능 무작위 1개, 0.5% 확률로 한 능력치 잠재력 +25 (천재 출현)
- **외모 유전**: 머리색·피부·눈·머리형 유전자를 부모 중 한쪽에서 50:50 → 가계도에서 닮은 게 눈에 보임
- **실제치는 유전 안 됨** → 부모가 잘 키워진 것과 자녀의 타고남은 별개
- 태교·임신 중 건강 이벤트로 약간 보정 가능 (v0.2)

## 5. 이벤트 시스템 (갈림길의 원천)

### 구조: 데이터 기반
모든 이벤트는 JSON 데이터. 코드 수정 없이 이벤트를 계속 추가할 수 있게.

```jsonc
{
  "id": "elem_school_choice",
  "trigger": { "age": 8, "who": "child", "era": ["*"] },
  "text": "{name}이(가) 초등학교에 갈 나이가 되었다.",
  "choices": [
    { "label": "동네 공립초",       "cost": 0,     "effects": { "flags": ["공립초"] } },
    { "label": "사립초",            "cost": 1500,  "req": { "wealth": 30000 },
      "effects": { "flags": ["사립초"], "int": "+growth", "network": 1 } },
    { "label": "국제학교",          "cost": 4000,  "req": { "wealth": 100000 },
      "effects": { "flags": ["국제학교"], "abroadPath": true } },
    { "label": "대안학교",          "cost": 800,
      "effects": { "flags": ["대안학교"], "happiness": 15, "discoverTalentChance": 0.3 } }
  ]
}
```

- **조건**: 나이, 능력치 실제치, 발견된 재능, 플래그(과거 선택), 시대, 재산, 관계도
- **선택지 표시**: 요구 조건(`지능 ★★★`, `비용 1,500만원`, `사립초 출신`)만 보임. 결과는 숨김
- **판정**: 선택지에 따라 능력치 체크 → 숨은 재능·잠재력이 맞으면 결과가 더 좋음
- **플래그 연쇄**: 초등 선택 → 중학 선택지 변화 → 고교 → 대학 → 직업. 이렇게 분기가 누적돼 경우의 수가 폭발함
- **자녀 의지**: 자녀의 `desire`와 가주 선택이 다르면 관계도·행복도 하락. 행복도가 낮으면 반항·가출·자퇴 이벤트. 원하는 길을 밀어주면 성장 보너스

### 나이 마일스톤 (직계)
| 나이 | 이벤트 | 대표 분기 |
|---|---|---|
| 0 | 출생 | 이름 짓기, 외모·재능 롤 |
| 5 | 유치원/어린이집 | 영어유치원 / 일반 / 집에서 → 첫 재능 힌트 |
| 8 | 초등 입학 | 공립 / 사립 / 국제 / 대안 |
| 10~12 | 적성 발견 창 | 영재원 시험, 운동부 스카우트, 오디션, 방치 |
| 14 | 중학교 | 일반 / 국제중 / 예체능 중 / 운동부 |
| 17 | 고교 진학 | 일반고 / 자사고·특목고 / 예고·체고 / 특성화고 / 자퇴→검정고시 |
| 19 | 수능·진로 | 명문대 / 지방대 / 해외유학 / 전문대 / 재수 / 취업 / 데뷔 / 프로 입단 |
| 20~22 | 군대 (남, 시대별) | 현역 / 장교 / 면제 / 대체복무 |
| 23~30 | 첫 직업 | 아래 직업표 |
| 25~40 | 혼인 창 | 후보 풀 |
| 결혼 후 | 가족계획 | 자녀 수 목표, 출산 |
| 50+ | 커리어 정점/위기 | 승진, 명퇴, 창업 실패, 스캔들 |
| 60+ | 은퇴 창 | 생전 승계, 증여, 유언장 작성 |

### 랜덤 이벤트 예시
질병·사고 / 친구의 보증 요청 / 로또 / 투자 권유(사기일 수도) / 자녀 연애 / 방계가 돈을 빌려달라고 함 / 이웃의 땅 매물 / 세무조사 / 바이럴 / 스캔들 / 시장 이벤트

- 시대별 등장/소멸: 유튜버는 2005년 이후, 프로게이머는 1999년 이후, 코인은 2013년 이후 …

## 7. 혼인·출산

- **후보 풀**: 혼인 창에서 매년 2~4명 등장. 공개 정보는 외모(초상화), 직업, 대략적인 집안 재산, 능력치 1~2개 정도. 잠재력·재능은 숨김
- **조건**: 좋은 후보는 본인 매력 / 가문 명성 / 재산 요구
- **경로**: 연애(행복도↑, 후보 질은 랜덤) / 중매(비용, 조건 맞춤) / 정략결혼(명성·재산↑, 행복도↓, 상대 가문과 연결)
- **혼수·예단**: 재산 이동 이벤트 (증여세 연결)
- **출산**: 가족계획(자녀 수 목표) → 나이·건강 기반 확률. 난임 이벤트, 쌍둥이 확률
- **이혼·재혼**: v0.2+

## 8. 경제

### 재산 화면 (은행 앱 스타일)
```
┌ 김씨 가문 총자산 ─────────── 48.2억 ┐
│ 가문 재산 (공동)            31.0억 │
│   가업 김가상사              18.0억 │
│   종가 토지(경기)            13.0억 │
│ 개인 재산                   17.2억 │
│   김철수(가주)  12.4억 ▸              │
│   김영희(배우자) 3.1억 ▸             │
│   김민준(장남)   1.7억 ▸             │
└──────────────────────────────┘
```
- 인물을 누르면 그 사람의 현금·예금·주식·아파트·차·예술품 목록이 나옴
- **가문 재산**: 가주가 관리하지만 개인 소유가 아님. 가주 사망 시 상속 대상은 개인 재산 + (규칙에 따라) 가문 재산 지분

### 자산 종류
| 종류 | 세부 | 특징 |
|---|---|---|
| 현금·예금 | — | 안전, 인플레이션으로 가치 하락 |

## 9. 상속·증여·세금

### 상속세 (실제 한국 세율 단순화)
| 과세표준 | 세율 |
|---|---|
| ~1억 | 10% |
| 1~5억 | 20% |
| 5~10억 | 30% |
| 10~30억 | 40% |
| 30억 초과 | 50% |
- 공제: 일괄공제 5억, 배우자공제(최소 5억)
- 가업상속공제: 조건(가업 경영 기간, 후계자 종사) 충족 시 큰 공제

### 증여
- 생전 증여: 자녀 1인당 10년간 일정액 비과세, 이후 누진세
- **10년 합산 규칙**: 사망 전 10년 이내 증여는 상속재산에 합산 → 증여는 일찍 할수록 유리 → 은퇴·증여 타이밍 전략

### 절세 (합법)
- 부동산으로 보유 (시가보다 낮게 평가)
- 가업상속공제
- 일찍부터 분산 증여
- 예술품 (평가 애매)
- 세무사 고용 (비용 ↔ 절감액)

### 탈세 (불법)
- 수단: 현금 은닉, 차명계좌, 예술품 저가 신고, 해외 계좌, 가업 비자금
- **세무 주목도**: 탈세할 때마다 누적. 시간이 지나면 조금씩 감소
- 세무조사 확률 = f(주목도, 재산 규모, 직업(정치인 등), 이벤트)
- 적발 시: 추징금(탈세액의 1.5~3배) + 명성 폭락 + 최악의 경우 수감(해당 인물이 몇 턴 동안 행동 불가)
- 세무사·로펌을 고용하면 완화됨. **공소시효(10~15년)** 가 지나면 안전

## 10. 승계·사망

- **사망 확률**: f(나이, 건강 실제치) + 질병·사고 이벤트
- **생전 은퇴**: 60세부터 가능. 후계자를 지명하고 증여 → 본인은 "원로"로 남음(조언 이벤트, 건강 관리)
- **유언장**: 개인 재산 분배율 설정. 작성 안 하고 죽으면 **법정상속(배우자 1.5 : 자녀 1)**
- **후계자 지명**: 장자·능력자·막내 누구든 지명 가능. 배제된 형제는 관계도에 따라:
  - 유류분 소송(법정상속분의 절반은 보장됨)
  - 분가(방계로 독립)
  - 악연(이후 랜덤 방해 이벤트)
  - 성품이 높은 형제는 수긍
- **새 본인**: 후계자가 가주가 되면 화면 중심이 이동. 이전 가주는 가계도 위쪽(부모 칸)으로 올라감
- **단절**: 직계가 없으면 방계(조카)나 양자로 승계 가능. 그것도 없으면 게임오버 → 최종 점수 결산

## 11. 명성·업적·미션

### 가문 명성
누적 점수. 올리는 방법: 직업 정점, 명문대, 공직, 기부, 대회 우승, 유명인 배출.
깎이는 원인: 스캔들, 탈세 적발, 범죄, 파산.
명성은 혼인 후보의 질, 정략결혼, 일부 직업 진입에 영향.

## 13. 화면 구성 (모바일 세로)

### 메인: 가계도
```
┌─────────────────────┐
│ 1987년  김씨 가문  48.2억 │  ← 연도·가문명·총자산
│─────────────────────│
│    [조부] [조모]          │  ← 위: 부모 세대 (작게)
│         │                 │
│ [형] ─ ★[본인]★ ─ [배우자] │  ← 중심: 본인, 옆: 형제·배우자
│         │                 │
│   [장남] [차녀] [막내]     │  ← 아래: 자녀
│     │                     │
│   [손자]                   │  ← 손주
│─────────────────────│
│ [방침] [자산] [연대기] [업적]│
│      [ ▶ 다음 해 ]         │
└─────────────────────┘
```
- 각 칸: 도트 초상화 + 이름 + 나이. 이벤트가 있는 인물에는 `!` 표시
- 핀치·드래그로 가계도 이동. 방계는 접혀 있다가 펼칠 수 있음

### 기타 화면
- **인물 상세**: 초상화, 능력치 막대(실제치 채움 / 잠재력은 `?` 또는 발견 후 표시), 재능 슬롯, 학력·직업, 관계도·행복도(아이콘)
- **이벤트 카드**: 삽화 영역(도트) + 텍스트 + 선택지 버튼(요구 조건 뱃지)
- **연간 방침**: 인물별 슬라이더와 토글
- **자산**: 은행 앱 스타일 (8장 참고)
- **연대기**: 가문 역사 타임라인 (세대별 요약. 공유용 스크린샷 각)

### 절차 생성 도트 초상화
- 캔버스 24×24px, 파츠 레이어: 얼굴형 / 피부 / 눈 / 머리형 / 머리색 / 옷(직업·시대)
- 나이 단계: 아기 / 아이 / 청소년 / 성인 / 노인 (주름, 흰머리)
- 유전자에서 결정적으로 생성 → 부모·자녀가 닮아 보임

## 14. 기술 설계

| 항목 | 선택 |
|---|---|
| 언어/빌드 | TypeScript + Vite |
| 렌더 | 가계도·초상화는 Canvas(픽셀 퍼펙트, `image-rendering: pixelated`), UI는 DOM |
| 상태 | 순수 함수형 시뮬레이션 코어 (`simulateYear(state, policy, choices) → state`). UI와 분리해서 테스트 가능 |
| 난수 | **시드 기반 RNG** → 재현 가능, 디버깅 가능 |
| 데이터 | 이벤트·직업·재능·시대·세율을 JSON/TS 데이터로 분리 |
| 저장 | localStorage(자동 저장) → 이후 IndexedDB, 클라우드 |
| 배포 | PWA (오프라인, 홈 화면 설치) → 필요하면 Capacitor로 앱스토어 |
| 테스트 | Vitest로 시뮬레이션 코어 검증 (유전 분포, 세금 계산, 100년 자동 플레이 스모크 테스트) |

### 디렉터리 초안
```
src/
  core/        # 시뮬레이션 (UI 없음)
    person.ts genetics.ts growth.ts economy.ts tax.ts
    events.ts succession.ts rng.ts year.ts
  data/        # 이벤트·직업·재능·시대·세율
  render/      # 캔버스 초상화, 가계도
  ui/          # 화면들
  save/
tests/
```
